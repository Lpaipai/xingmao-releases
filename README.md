# 星锚 TV

连接每一屏的精彩。

星锚 TV 面向投影仪、TV、手机等 Android 设备，支持遥控与触控操作。

## 下载安装

前往 [最新版本](https://github.com/Lpaipai/xingmao-releases/releases/latest)，下载 `xingmao-版本号.apk` 并安装。最低 Android 6，支持 ARM v7a 与 ARM64；具体设备兼容性以实际体验为准。

每次进入应用会自动检查更新，也可在「控制中心 → 检查应用更新」手动查看。更新在后台下载，完成后由 Android 系统确认安装。覆盖安装可保留收藏和设置，请勿先卸载旧版。

## 使用

- 遥控器确定键打开频道列表，菜单键或右键打开控制中心；“暂停／恢复直播”位于设置菜单第一行。
- 触屏单击画面显示“频道、设置”入口，双击暂停或恢复直播。
- 控制中心可调整背景透明度；菜单子页面按返回回到上一级。
- 控制中心和关于页面显示与你相遇的天数。
- 播放时可暂停或恢复直播；暂停后下载更新不再受播放优先的限速约束。
- 更新页可查看下载进度并取消任务；系统首次安装授权需在设备上完成。
