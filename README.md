# 星锚 TV

连接每一屏的精彩。

星锚 TV面向投影仪、TV、手机等 Android 设备，支持遥控与触控操作。

## 下载安装

前往 [最新版本](https://github.com/Lpaipai/xingmao-releases/releases/latest)，下载 `xingmao-版本号.apk` 并安装。最低 Android 6，支持 ARM v7a 与 ARM64；具体设备兼容性以实际体验为准。

安装后可通过「控制中心 → 检查应用更新」获取新版本。更新需要网络连接，安装由 Android 系统确认。覆盖安装可保留收藏和设置，请勿先卸载旧版。

## 使用

- 确认键或轻点画面打开频道列表，菜单键或右键打开控制中心。
- 控制中心可调整背景透明度；菜单子页面按返回回到上一级。
- 控制中心和关于页面显示与你相遇的天数。
- 下载更新时可按返回取消；系统首次安装授权需在设备上完成。
